# RedVital - Proyecto IntegraSupply Regional
**Repositorio de Modelos de Control, Gestión de Riesgos y Evaluación EVM**

Este repositorio contiene los modelos cuantitativos, matrices de control y tableros de seguimiento desarrollados para la protección del valor en la operación logística regional de **RedVital**.

## Contenido del Repositorio

1. **`01_Matriz_de_Riesgos_y_Control.xlsx`**: Matriz de riesgos clasificados (Nuevos, Residuales y Emergentes) con planes de mitigación y umbrales de alerta.
2. **`02_Modelo_EVM_Valor_Ganado.xlsx`**: Hoja de cálculo automatizada con métricas de Valor Ganado al Mes 3 (BAC, EV, PV, AC, CPI, SPI, EAC, TCPI).
3. **`03_Tablero_de_Calidad_y_SLA.xlsx`**: Tablero de seguimiento para trazabilidad de pedidos (58%), tasas de error y cumplimiento de proveedores.
